## 2. 主任务：多平面波相干复合（7 小时，+80%）

### 2.1 先讲清物理直觉（先定义后例子）

**为什么单平面波质量差？**
单平面波（θ=0）发射时，声波是一整片平面往下打，**没有聚焦**。接收时各阵元虽然能靠 DAS 的时延对齐，但横向（x 方向）的「聚焦能力」受限于阵列孔径，所以亮点横向偏宽、还有旁瓣伪影。

**多平面波相干复合（Coherent Plane-Wave Compounding, CPWC）是什么？**
用**不同角度**的平面波发射多次（比如 -5°、-2.5°、0°、2.5°、5°），每次都做一次 DAS 得到一张图，然后把这几张图**相干叠加**。多个角度从不同方向「看」同一个散射体，叠加后等效于**合成孔径/合成聚焦**，横向分辨率显著改善、旁瓣压低。

**关键定义：**
- **发射角度 θ**：平面波波前的法线方向与 z 轴的夹角；θ=0 是垂直向下，θ>0 是朝 +x 方向倾斜。
- **倾斜波前发射时延**：波前在 t=0 时通过原点，传到散射体 (x, z) 的时间 = `(x·sinθ + z·cosθ) / c`（就是散射体在波前法线方向上的投影距离 / 声速）。θ=0 时退化成 `z/c`，和你 11/5 学的一致。
- **相干复合**：多个角度的 DAS 结果直接相加（这里是相干叠加；真实超声里还要考虑包络/相位，今天先用高斯脉冲简化，相加即可）。

### 2.2 第 1 步：多角度发射，生成 RF（第一项「自己写」）

在 11/5 的 `make_rf` 基础上，把「发射时延」从 `z/c` 改成 `(x·sinθ + z·cosθ)/c`。要求自己写，写不出再看参考：

```python
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "DejaVu Sans"]
plt.rcParams["axes.unicode_minus"] = False

# ===== 参数（复用 11/5）=====
c = 1540.0
fs = 40e6
N = 64
pitch = 0.3e-3
sigma = 0.05e-6
elem_x = (np.arange(N) - (N - 1) / 2) * pitch

scatterers = np.array([
    [ 0.0e-3, 15e-3, 1.0],
    [ 3.0e-3, 20e-3, 0.7],
    [-3.0e-3, 25e-3, 0.5],
])

z_max = 40e-3
t_axis = np.arange(0, 2 * z_max / c, 1 / fs)

# ===== 多角度发射：生成 RF =====
def make_rf(theta):
    """theta（弧度）：平面波发射角度。返回 (N, T) 的 RF。"""
    rf = np.zeros((N, len(t_axis)))
    for xk, zk, amp in scatterers:
        for i in range(N):
            tau = (xk * np.sin(theta) + zk * np.cos(theta)) / c \
                + np.sqrt((xk - elem_x[i]) ** 2 + zk ** 2) / c
            rf[i] += amp * np.exp(-((t_axis - tau) ** 2) / (2 * sigma ** 2))
    return rf
```

### 2.3 第 2 步：带角度的 DAS（第二项「自己写」）

DAS 重建像素 (x,z) 时，发射时延也要用**该角度 θ 的几何**（不能固定用 z/c）：

```python
def das(rf, theta):
    nx, nz = 256, 512
    x_grid = np.linspace(-10e-3, 10e-3, nx)
    z_grid = np.linspace(2e-3, 40e-3, nz)
    X, Z = np.meshgrid(x_grid, z_grid)
    image = np.zeros((nz, nx))
    for i in range(N):
        tau = (X * np.sin(theta) + Z * np.cos(theta)) / c \
            + np.sqrt((X - elem_x[i]) ** 2 + Z ** 2) / c
        idx = np.round(tau * fs).astype(int)
        idx = np.clip(idx, 0, len(t_axis) - 1)
        image += rf[i, idx]
    return image, x_grid, z_grid
```

    d = np.abs(img)
    return 20 * np.log10(d / d.max() + 1e-6)

    plt.figure(figsize=(6, 8))
    plt.imshow(disp_db(img),
               extent=[x_grid[0]*1e3, x_grid[-1]*1e3, z_grid[-1]*1e3, z_grid[0]*1e3],
               cmap="gray", aspect="auto", vmin=-60, vmax=0)

# 单平面波（θ=0）→ 低质量图

## 3. 信号：F 数 / 切趾直觉（40 分钟，一句话级）

不推导，只建立直觉（规则 17 允许的深度）：

- **F 数（F-number）**：`F = 焦距 / 孔径`。F 数越小（孔径越大/焦距越短），聚焦越「紧」，横向分辨率越好，但焦深越浅。多平面波复合本质就是「合成一个更大的等效孔径 → 等效 F 数变小 → 分辨率变好」。
- **切趾（apodization）**：给各阵元加「窗权重」（中间权重大、两边小），压低旁瓣，代价是主瓣变宽。你 11/4 学的「三点滑动平均/窗」在空间上的对应物就是切趾。

**写进笔记一句话**：多平面波复合 = 用「多个角度」换「等效大孔径」，是超快超声提高质量的核心手段；F 数和切趾是量化/优化这套几何的两个直觉工具。
