## 2. 主任务 1A（代码实验）：加噪声/衰减重扫 K 曲线（~40min，AI 写）

> 昨天结论：自仿真临界 K≈49 偏大，因为「无噪声/无衰减，每加一个角度都有真实增益」。真实超声有电子噪声 + 深度衰减，饱和会提前到 K=10~20。今天验证这一点。

AI 写代码（复用 `us_recon_kcurve/scan_k.py`，用户跑 + 验证）：

1. **电子噪声**：`rf += noise`，噪声幅度按 SNR 控制（先 SNR≈30 dB，再试 20 dB）。
2. **深度衰减**：每个散射体幅度乘 `exp(-alpha * f * z)`，`alpha ≈ 0.5 dB/cm/MHz`（软组织典型值），深点衰减更多。
3. 重扫 K ∈ {1,3,5,9,15,25,37,49,61,75}，指标**只采信 PSNR/SSIM**（昨天已判点恢复率/gCNR 参照系有误）。
4. 用增量法找临界 K，看是否从 49 回落到 10~20。

**验收**：新 K 曲线图 + 一句话临界 K 结论。**变式（有余力）**：只加噪声 / 只加衰减 / 都加，2×2 消融，看谁主导饱和提前。

## 2.5 主任务 1B（代码实验第二半）：正确参照系补「保组织」指标（~40min，AI 写）

> 昨天诚实边界：点恢复率用「峰值归一化」掩盖丢点、gCNR 有「分布可分度」陷阱，参照系（K=75 图）有误，不采信。今天用**正确参照系**补上「保组织」这一维。

AI 写代码（用户跑 + 验证）：

- **正确参照系 = 理想高斯点图**：每个散射体位置放一个理想高斯点（11/24 H2 已用过这个做法）。
- 对每个 K，算 `compound(K)` 的「点恢复率 = 图在点位置峰值 / 理想点图峰值」（**不峰值归一化，直接比幅值**）。
- 画「点恢复率 vs K」曲线，回答：**K 从少到多，真实点目标被保留了多少？少角度时有没有把真实点抹掉？**

**验收**：一条「点恢复率 vs K」曲线 + 一句话「少角度是否丢真实点」——这是「去伪影 vs 保真组织」权衡的跨角度证据，直接服务 gap。

## 4. Verasonics 学习：阶段 1 概念（20–30min）

> 目标 = 硬件一到就能快速上手。今天只建立「脚本长什么样」的概念，不碰 MATLAB、不跑。

- 记住一句骨架：**Verasonics 脚本 = ① 用 MATLAB 结构体定义参数 ② 定义一个事件序列（先发射→再接收→再重建）**。
- 把 8 个结构各写一句话（人话，不是定义）：

| 结构 | 管什么 |
|---|---|
| `Trans` | 换能器（频率/阵元数/几何） |
| `Resource` | 硬件资源（缓冲、通道数） |
| `TX` | 发射（波形、切趾、延时） |
| `Receive` | 接收（采样、孔径、TGC） |
| `Recon` + `ReconInfo` | 重建参数（像素网格、波束形成方式） |
| `PData` | 像素数据（图像网格定义） |
| `SeqControl` | 时序控制（事件间隔等） |
| `Event` | 事件序列（把上面串起来的执行顺序） |

**验收**：能不看表复述「脚本 = 定义参数 + 排事件」，8 个结构各一句。写进当天记录。

### 5.1 端侧部署的 5 步链（10min，先记住这条链）

**模型训好（PyTorch）→ 导出 ONNX → 转 TensorRT / INT8·FP16 量化 → 用 C++ 写推理 → 部署到边缘设备。**

- 记一句：**Python 用来训，C++ 用来跑（推理）**。Python 慢、占内存、不能直接跑在设备上，所以落地要 C++ + 推理框架。

### 5.2 C++ 第一个概念：指针（10min，手写笔记，不用编译器）

- 一句话定义：**指针 = 存「地址」的变量**。`int x = 5;` 声明一个整数；`int* p = &x;` 里 `p` 存的是 `x` 的地址，`*p` 是「顺着地址取到 x 的值」。
- 手写笔记（3 行，先读懂，不用跑）：`&` 取地址、`*` 解引用（取值）、`int* p` 声明指针。
- **今天不配 C++ 编译器**，只把这个「地址 vs 值」的概念记牢；环境后面再配。

**验收**：能说出「端侧部署 5 步链」+「指针 = 存地址，`&` 取地址、`*` 取值」。
