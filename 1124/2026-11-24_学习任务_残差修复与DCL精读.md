## 2. 主任务：残差修复尝试 1（3h）

> 对应 11/17 执行总纲创新点 A + 11/18 的 H2 假设（亮点丢失根因 = 过平滑）。

### 2.1 残差学习改造（~1h）

- 网络输出改成学**残差 Δ = 高质 − 低质**，最终重建 = 低质 + Δ（只学增量，不重学整图）。
- 复用 `us-recon/models/` 的网络，改输出头 + 前向加 skip 连接（低质 + Δ）。

### 2.2 点目标/边缘加权损失（~1h）

- 在 `us-recon/losses/` 加一个加权 MSE/MAE：对**强点区域**和**边缘区域**加权，让 loss 盯住稀疏强反射，别被背景均值淹没。
- 权重来源：低质图的高强度像素 / 梯度幅度（先做一版简单可跑的）。

### 2.3 四指标对比 baseline（~1h）

- 用 `us-recon/metrics/` 里的指标，对比 **baseline（11/9 三张图：低质 / DL 重建 / 高质）vs 修复版**。
- 四指标：PSNR / SSIM / CNR / gCNR（点目标恢复率有余力加第五个）。
- 数据复用 `2026-11\1109\stepC_full_rebuild.py` 的 低质 / 高质。

**验收**：四指标对比表 + 一句话结论（**点目标恢复率有没有回升**）。落盘当天记录并回填 `us-recon/README.md` 结果表。

**变式（有余力）**：只加残差不加加权 / 只加加权不加残差，做 2×2 小消融，看哪个在起作用。

## 3. 信号/物理：为什么「过平滑」会丢亮点（1h）

- 点散射体是**稀疏强反射**（幅度远高于背景），MSE/回归倾向**均值**，强点被抹平（过平滑）。
- 残差学习只补「增量」、强点加权让 loss 盯住稀疏强点——写一段人话 + 公式层面一句话（加权 loss 里 w 对强点取大值）。
