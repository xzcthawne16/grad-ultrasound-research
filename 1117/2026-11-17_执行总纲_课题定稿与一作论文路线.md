## 1. 方向地图与最终选择

- 它本质是 AI 圈成熟的 **learned image reconstruction / image-to-image** 问题，不是「信号处理」题。
- 信号负担已被 11/9 跑通的 DAS 消化；剩余 85% 是网络设计、训练、评价、部署（= 你的代码主场）。
- 已有跑通基线（自仿真 PSNR+4.46、PICMUS +10.30/SSIM 0.9936），起点高、切换成本零。
- 直接回应导师两问（伪影 vs 真组织、亮点丢失）。

## 3. 课题（2026-11-18 已锁定）

**中文题目**：《面向少角度平面波超声的「保细节·抗伪影」学习式重建：残差学习 + 数据一致先验 + 自监督增强》

**English working title**：Detail-Preserving, Artifact-Aware Learned Reconstruction for Few-Angle Plane-Wave Ultrasound: Residual Learning with Data-Consistency Priors and Self-Supervised Enhancement

- **研究问题**：减少平面波发射（提帧率）时，如何让 DL 重建在抑制伪影的同时不丢真实组织，并在无真值下可自证。
- **创新点**：
  - A（主）：残差学习（只学 高质−低质 增量）+ 保细节损失（强点/边缘加权）+ 数据一致项（输出须通过 DAS 前向回到输入，防幻觉）；
  - B（护城河）：可学习波束形成（学 DAS 时延/SoS/逐通道权重）；
  - C（扩展）：无配对/自监督训练 + 无真值验证协议（CNR/gCNR/FWHM/一致性）。
- **数据三级**：自仿真（可控伪影）→ PICMUS（已有）→ CUBDL（真实 RF + in vivo benchmark）。
- **算力三级**：本机 4060（日常 80%）→ 实验室服务器（先问导师）→ 云端租卡（自监督预训练/扩散对比，月 ¥200–300）。
- **指标**：PSNR/SSIM（同口径）+ CNR/gCNR + FWHM/点目标恢复率 + 一致性。

## 4. 一作论文：直冲顶刊 + 单一退路（2026-11-17 定）

- **概念对齐**：SCI 1区是「分区」不是「期刊级别」；顶刊 ⊂ 1区。对医疗 CV 岗，最对口且含金量最高的顶刊 = **IEEE TMI / MedIA**（+ 会议 MICCAI）。Nature Communications 影响因子高但医疗 CV 岗更认 TMI/MedIA。
- **主投（唯一目标）**：**TMI 或 MedIA**（中科院 1区 Top + 医疗影像顶刊）。
- **单一预置退路**：**TUFFC 或 JBHI**（仍 1区/2区、简历够硬）。作用：顶刊被拒后，同一份工作几周内转投落地，不浪费一年。**这是「瞄准最高 + 保护努力」，不是阶梯。**
- **诚实边界**：TMI/MedIA 录用率约 15–25%，一审 2–6 月、全程 6–14 月，审稿有随机性。预算+努力提高概率、不保证命中。
- **预算投向四件事**：① novelty 定位评审（**本周就做**）② 实验设计评审 ③ 写作润色 ④ rebuttal。
- **时间线**：研一上锁课题 → 研一下~研二上出方法+投稿 → 研二拿到录用。

### 4.1 科研辅导协作规则（有预算，不代写）

四个高杠杆时刻：① 选题/novelty 定位评审（现在~11 月底）→ ② proposal/实验设计（12 月）→ ③ 写作/英文润色（投稿前 2–4 周）→ ④ rebuttal 策略（收意见后）。
边界：方法/实验/代码/初稿必须自己产出；辅导只做「评审 + 润色」。不花预算在教基础/教代码（助手免费做）。代写 = 学术不端，会撤稿/黑名单。

## 7. agent 支线 + 简历「1+N」

- **agent 支线（B3/B4）**：把你的重建模型当前端 + 轻量检测 + LLM(RAG) 生成结构化报告 + 证据引用，做「AI 超声辅助诊断 agent」。只复用现有 LLM + 你的算法，不追新模型/框架；时间 ≤20%；两周选题期不碰。
- **简历「1+N」**：1 = 主线重建项目（可复现 + 量化指标）；N = agent 支线 + （可选）标注高效分割小项目。共享「把算法交付成可用产品」的能力，互为护城河与退路。
