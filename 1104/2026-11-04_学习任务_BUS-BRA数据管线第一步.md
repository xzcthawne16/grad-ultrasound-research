### 2.3 第 2 步：结构侦察（第一项「自己写」，跑下面的侦察脚本）

先别手动翻文件管理器，直接写/跑一段脚本把结构**自动打印出来**。要求自己先写，写不出来再看下面的参考（参考里的路径按你实际解压位置改）。

```python
from pathlib import Path
from collections import Counter

data_dir = Path(r"E:\develop\Graduate_AI\learning-lab\data\BUSBRA")

# (a) 打印目录树（最多 3 层，避免刷屏）
def walk(p, depth=0, max_depth=3, max_items=80):
    if depth > max_depth:
        print("  " * depth + "...")
        return
    items = sorted(p.iterdir())
    for it in items[:max_items]:
        if it.is_dir():
            print("  " * depth + f"[dir] {it.name}/")
            walk(it, depth + 1, max_depth, max_items)
        else:
            print("  " * depth + f"{it.name}  ({it.stat().st_size:,} B)")
    if len(items) > max_items:
        print("  " * depth + f"... 还有 {len(items) - max_items} 项未显示")

print("=== 目录树 ===")
walk(data_dir)

# (b) 统计文件类型
exts, total = Counter(), 0
for f in data_dir.rglob("*"):
    if f.is_file():
        exts[f.suffix.lower()] += 1
        total += 1
print("\n=== 文件总数:", total, "===")
print("按扩展名:", dict(exts))

# (c) 找出「可能的标签文件」（图片之外的结构化文件）
label_cands = [f for f in data_dir.rglob("*")
               if f.suffix.lower() in {".csv", ".tsv", ".xlsx", ".xls", ".txt", ".json"}]
print("\n=== 可能的标签/元数据文件 ===")
for f in label_cands:
    print(" ", f.relative_to(data_dir))
```

## 3. 信号：三点滑动平均滤波（1–1.5 小时）

接规则 17：主线验收之一是「三点滑动平均怎么手算」。今天做它，**用途接到重建链的「去噪/后处理」位置**（重建输出图之后、显示/算指标之前）。

### 3.1 先手算（纸/注释里写清楚）

给一维序列 `x = [1, 3, 2, 4, 1]`，用三点滑动平均（窗长 3）手算出输出。把每个输出点 `y[i] = (x[i-1] + x[i] + x[i+1]) / 3` 怎么来的写出来，并说明**两端的点怎么处理**（最容易出错的地方）。

### 3.2 代码＋前后对比图（先自己写，再看参考）

```python
import numpy as np
import matplotlib.pyplot as plt
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "DejaVu Sans"]
plt.rcParams["axes.unicode_minus"] = False

# (a) 手算对应：x = [1,3,2,4,1] 的三点滑动平均
x = np.array([1, 3, 2, 4, 1])
y_valid = np.convolve(x, np.ones(3) / 3, mode="valid")  # 只算有完整窗的点 → 长度变短
y_same  = np.convolve(x, np.ones(3) / 3, mode="same")   # 边界补零 → 保持长度
print("原始 x       :", x)
print("valid(变短)  :", y_valid)
print("same(等长)   :", y_same)
# 对照手算：y[1] = (1+3+2)/3 = 2.0，y[2] = (3+2+4)/3 = 3.0，y[3] = (2+4+1)/3 = 2.333...

# (b) 含噪正弦滤波前后对比
fs = 100
t = np.linspace(0, 1, fs, endpoint=False)
sig = np.sin(2 * np.pi * 2 * t)                       # 2Hz 干净信号
noise = 0.4 * np.random.default_rng(0).randn(fs)      # 高斯噪声（固定种子可复现）
xn = sig + noise                                       # 含噪信号
yn = np.convolve(xn, np.ones(3) / 3, mode="same")      # 三点滑动平均

fig, axes = plt.subplots(2, 1, figsize=(9, 6), sharex=True)
axes[0].plot(t, sig, "--", label="干净信号", alpha=0.7)
axes[0].plot(t, xn, alpha=0.5, label="含噪")
axes[0].set_title("滤波前"); axes[0].legend()
axes[1].plot(t, sig, "--", label="干净信号", alpha=0.7)
axes[1].plot(t, yn, label="三点滑动平均后")
axes[1].set_title("滤波后"); axes[1].legend(); axes[1].set_xlabel("t (s)")
fig.tight_layout()
plt.show()
```

**先预测再运行**：三点滑动平均后，高频毛刺（噪声）是变多还是变少？波形是不是更「钝」、相位有没有滞后？跑完对照预测。

### 3.3 一句话结论（写进笔记）

三点滑动平均＝用邻近 3 点的均值代替当前点，是低通滤波，能压高频噪声、代价是让信号变「钝」；边界点要单独约定（valid 变短 / same 补零）。在重建链里它就是**后处理去噪**，不是核心重建。
