# DiffPWI 前沿阅读读书卡（2026-11-25，前沿泛读块）

> 定位：前沿泛读（15min 档），只读标题+摘要+结论，记「它在做什么 / 对我启发」。比精读卡（DCL / BEAM-Net）简略，但要能一眼看出它和你 gap 的关系。

## 论文信息

- **标题**：DiffPWI: A degradation-aware diffusion model for ultrasound plane-wave imaging
- **作者**：Chang Shaowei, Chen Chuan, Ge Fuhua, Qiu Weibao, Yu Yanyan, Zhou Guang-Quan
- **来源**：*Ultrasonics*（2026-09 在线），DOI 10.1016/j.ultras.2026.108300
- **数据**：PICMUS（phantom）+ 自建多器官 in vivo + zero-shot 数据集

## 它要解决的问题（一句话）

稀疏角度平面波成像（PWI）以图像质量换帧率，现有深度学习重建**缺物理退化建模**，且**低频谱偏置会衰减高频分量**，导致「解剖结构失真 + 斑点统计失真 + 细节丢失」。

## 核心方法（一句话）

用**潜在扩散模型（LDM）**学「物理退化的分布」当先验，再加一个**频率解耦注意力模块（FDAM）**把特征拆成分层频率子带，一边保高频解剖细节、一边压伪影。

## 关键评价指标

| 类别 | 指标 | 测什么 |
|---|---|---|
| 空间分辨率 | FWHM（横向点目标剖面） | 点扩散宽度 |
| 对比度 | CR / CNR / gCNR | 消声区 vs 背景 |
| 斑点保真 | speckle fidelity（斑点统计相似） | 散斑像不像 GT |

> 注：DiffPWI 把「斑点保真（speckle fidelity）」列为三大验证目标之一，比 DCL/Modular 更靠近「保真实组织」，但仍停留在**图像域相对相似**，没有「已知真点物理真值」的绝对保真验证。

## 读书卡三问

| 维度 | 内容 |
|---|---|
| **它做什么** | 用扩散模型学物理退化先验 + 频率解耦注意力，把「保高频细节」做成显式目标，从稀疏角度 PWI 重建高保真图 |
| **我差在哪** | 它解决「保高频细节」用的是**图像域频率子带分解**（FDAM），验证靠 speckle fidelity 这种**相对相似度**；**没有「已知真点 + 已知消声区」的物理真值自证链**，无法回答「重建是不是真的没丢真实散射体」 |
| **能不能抄** | ①「低频谱偏置 → 高频细节丢失」这个**根因诊断**可直接引用，作为「为什么 DL 重建会丢细节」的理论支撑；②「退化先验（LDM）把『伪影』和『真结构』分离」的思想可借鉴到我「去伪影 vs 保组织」权衡的建模 |

## 一句话总结（对你最关键）

> 到 2026 年，「保细节」已从盲区变成**显式竞争点**（DiffPWI 的 FDAM 专门对抗高频细节丢失）。你的 gap 方向正确、但**紧迫性上升**；你的差异化必须落到「物理真值层的绝对保真」（已知真点恢复率 + 已知消声区权衡量化），而不是停在「图像域相对保真」（EPI / speckle fidelity / 频率子带）——后者前沿已经在做了。

## 概念速记（两个骨架词，用超声场景讲）

### 1. 扩散模型（Diffusion Model）

**本质**：先学「把清晰图一步步加噪变成纯噪声」（前向，公式固定不用学），再学「从纯噪声一步步去噪还原清晰图」（反向，网络学）。

**DiffPWI 的巧思**：不让扩散模型直接「生成 B 超图」（太难、易幻觉假结构），而是让它**只学「伪影/退化」的分布**。因为稀疏角度图和满角度图对应同一解剖结构，差异主要就是采集退化（PSF 展宽、旁瓣、相干伪影），所以只建模这部分退化 → 得到「**退化先验**」→ 喂给重建网络。

> 类比：不学「怎么画一幅画」，只学「墨渍、划痕、反光长什么样」，知道了干扰的样子，就能精准擦掉干扰而不伤画本身。这就是「degradation-aware（退化感知）」。

### 2. 注意力机制（Attention Mechanism）

**本质**：让网络在每层学会「该重点看哪里、哪些位置有关系」，而不是对整张图一视同仁地局部平均处理。弥补普通卷积「固定窗口、只看邻居」的局限。

**FDAM（频率解耦注意力）具体做法**：把特征**按频率拆成子带**（低频 = 大轮廓/组织整体；高频 = 边缘/点目标/细颗粒），再用注意力**自适应**决定：哪些高频子带该保留（真细节）、哪些该压掉（伪影）——在频率维度动态调和「保细节 vs 压伪影」的矛盾，而不是一刀切。

### 3. 两者合起来的完整逻辑链

```
稀疏角度图 ─► 对比满角度图 ─► 差异 = 采集退化
                                    │
                  扩散模型学「退化先验」（知道伪影长什么样）
                                    │
                                   ▼
              重建网络 + FDAM（频率解耦注意力）
              按频率动态：保高频真细节 / 压伪影
                                    │
                                   ▼
                          高保真重建图
```

- 扩散模型回答「**伪影是什么**」（退化先验）；
- 注意力机制回答「**哪些是真细节、哪些是伪影，分别怎么处理**」（频率解耦）。

### 4. 对你的直接意义

扩散先验 + FDAM 全发生在**图像/特征域**，本质是「让图更像满角度参考图」，**没有「已知真点 + 已知消声区」的物理真值**来检验「保下来的高频是不是真实散射体，还是幻觉出来的假细节」。你的工作正是给「保细节」加上**物理真值锚点**，回答图像域方法回答不了的问题：**「去的是伪影，不是真组织」**。
