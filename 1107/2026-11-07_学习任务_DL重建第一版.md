### 2.0 先定义：分类 → 回归，改的是哪几处？（规则 2：先定义后上手）

你 11/2 做的是**分类**（手写数字 10 类）。今天做**逐像素回归**。对照：

| 维度 | 分类（11/2） | 逐像素回归（今天） |
|---|---|---|
| 输出 | 10 个类别分数 | 一张和输入同尺寸的图，每像素一个连续值 |
| 最后一层 | `Linear(→10)` | `Conv2d(→1)`，**不加** softmax/激活 |
| 损失 | `CrossEntropyLoss` | `MSELoss`（均方误差） |
| 评价 | accuracy | PSNR / SSIM |
| 目标 | 正确类别 | 预测图 ≈ 高质图（逐像素接近） |

**一句话**：回归输出的是「连续数值」（每个像素该多亮），所以用 MSE 度量「差多少」，用 PSNR/SSIM 看「像不像」；分类输出的是「离散类别」，用交叉熵度量「分没分对」。

> ⚠️ **诚实边界（Perdios 已提醒，组会要讲）**：超声里 PSNR/SSIM 是「图像依赖、不可跨实验直接比较」的指标。今天算它是为了**在同口径内做 baseline 对比**（低质图 vs DL 重建图，同一批数据、同一归一化），不是拿去和别的论文比绝对数字。口径一致才可比。

### 2.1 第 1 步：批量生成配对数据集（自己写）

昨天只存了 **1 对**，训练需要**几百对**。把 11/6 的仿真函数复用，随机散射体位置/幅度，批量造出 N 对「低质/高质」dB 图。

> 关键区别：昨天散射体是**固定 3 个**；今天要**随机**（随机数量、位置、幅度），否则网络只会背那一张图，不是「学恢复」。

```python
import numpy as np

c, fs, N, pitch, sigma = 1540.0, 40e6, 64, 0.3e-3, 0.05e-6
elem_x = (np.arange(N) - (N - 1) / 2) * pitch
z_max = 40e-3
t_axis = np.arange(0, 2 * z_max / c, 1 / fs)

def make_rf(theta, sc):
    """sc: (M,3) 散射体 [x, z, amp]。返回 (N, T) RF。"""
    rf = np.zeros((N, len(t_axis)))
    for xk, zk, amp in sc:
        for i in range(N):
            tau = (xk*np.sin(theta) + zk*np.cos(theta))/c \
                + np.sqrt((xk - elem_x[i])**2 + zk**2)/c
            rf[i] += amp * np.exp(-((t_axis - tau)**2)/(2*sigma**2))
    return rf

def das(rf, theta, nx=256, nz=512):
    x_grid = np.linspace(-10e-3, 10e-3, nx)
    z_grid = np.linspace(2e-3, 40e-3, nz)
    X, Z = np.meshgrid(x_grid, z_grid)
    img = np.zeros((nz, nx))
    for i in range(N):
        tau = (X*np.sin(theta) + Z*np.cos(theta))/c \
            + np.sqrt((X - elem_x[i])**2 + Z**2)/c
        idx = np.clip(np.round(tau*fs).astype(int), 0, len(t_axis)-1)
        img += rf[i, idx]
    return img, x_grid, z_grid

def disp_db(img):
    d = np.abs(img)
    return 20*np.log10(d/d.max() + 1e-6)      # 对数压缩 → dB 图

def rand_sc(n):
    return np.array([(np.random.uniform(-8e-3, 8e-3),
                      np.random.uniform(5e-3, 35e-3),
                      np.random.uniform(0.3, 1.0)) for _ in range(n)])

angles = np.deg2rad(np.array([-5, -2.5, 0, 2.5, 5]))

def make_pair():
    sc = rand_sc(np.random.randint(3, 8))     # 随机 3~7 个散射体
    lo, _, _ = das(make_rf(0.0, sc), 0.0)     # 低质：单平面波
    hi = np.zeros_like(lo)
    for th in angles:
        hi += das(make_rf(th, sc), th)[0]     # 高质：5 角度相干复合
    hi /= len(angles)
    return disp_db(lo), disp_db(hi)
```

**跑完要能回答**：① 为什么散射体必须随机，不能固定？（固定=网络背答案）② `disp_db` 输出的数值范围大致是多少 dB？（约 [−60, 0]，动态范围 60 dB）

### 2.3 第 3 步：搭逐像素回归网络（自己写）

复用你会的 `Conv2d`，关键：**全部 padding=1 保持尺寸不变**，最后一层 `Conv2d(→1)` 不加激活。

```python
import torch.nn as nn

class ReconNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(1, 16, 3, padding=1), nn.ReLU(),
            nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(),
            nn.Conv2d(32, 16, 3, padding=1), nn.ReLU(),
            nn.Conv2d(16, 1, 3, padding=1),      # 输出 1 通道，无激活
        )
    def forward(self, x):
        return self.net(x)
```

**跑完要能回答**：① 为什么这里是 `Conv2d(→1)` 而不是 `Linear(→10)`？② 为什么最后一层**不加** ReLU/softmax？（回归要输出任意连续值，激活会截断/归一化）

### 2.5 第 5 步：PSNR/SSIM + baseline 对比（今日核心，信号块并入）

手写两个指标（只用 torch，不装额外库）：

```python
import torch.nn.functional as F

def psnr(a, b, maxv=1.0):
    mse = F.mse_loss(a, b)
    return 10 * torch.log10(maxv**2 / mse).item()

def gaussian_kernel(size=11, sigma=1.5):
    c = torch.arange(size, dtype=torch.float32) - size // 2
    g = torch.exp(-(c**2) / (2*sigma**2)); g = g / g.sum()
    k = g[:, None] * g[None, :]
    return k.view(1, 1, size, size)

_W = gaussian_kernel()

def ssim(a, b, C1=1e-4, C2=9e-4):
    w = _W.to(a.device); pad = 5
    mu1 = F.conv2d(a, w, padding=pad); mu2 = F.conv2d(b, w, padding=pad)
    s1 = F.conv2d(a*a, w, padding=pad) - mu1**2
    s2 = F.conv2d(b*b, w, padding=pad) - mu2**2
    s12 = F.conv2d(a*b, w, padding=pad) - mu1*mu2
    m = ((2*mu1*mu2+C1)*(2*s12+C2)) / ((mu1**2+mu2**2+C1)*(s1+s2+C2))
    return m.mean().item()

# ---- baseline 对比（规则 19：同口径、先有 baseline）----
model.eval()
with torch.no_grad():
    pred = model(Xte)
    print("baseline(输入即低质图): PSNR=%.2f dB  SSIM=%.4f" % (psnr(Xte, Yte), ssim(Xte, Yte)))
    print("DL 重建:                PSNR=%.2f dB  SSIM=%.4f" % (psnr(pred, Yte), ssim(pred, Yte)))
```

## 3. 信号：PSNR/SSIM（已并入主任务第 5 步）

**PSNR（峰值信噪比）**：`10·log₁₀(MAX²/MSE)`，衡量「重建误差相对信号峰值有多小」，单位 dB，越大越好。
**SSIM（结构相似度）**：综合**亮度、对比度、结构**三方面（通过局部均值/方差/协方差），范围 [−1,1]，越接近 1 越像；比 MSE 更贴近人眼「像不像」。

一句话记进笔记：**PSNR 只看逐像素误差，SSIM 看结构像不像**；两者结合、且必须同一归一化口径下对比才有意义。
