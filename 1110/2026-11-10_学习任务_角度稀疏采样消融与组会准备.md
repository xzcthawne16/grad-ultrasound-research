## 2. 主任务 A：PICMUS 创新点增量——角度稀疏采样消融（1.5 小时，轴 B 直接实证）

### 2.0 为什么这个创新点「值钱」？（先想清楚再写代码）

导师创新轴 B = **「更少数据同等质量」**。你现在做的是「1 个角度（低质）→ 75 个角度复合（高质）」这一个点。创新点把它变成**一条曲线**：

> 固定输入=1 角度；把「高质目标」换成 K 个角度复合，K = 1, 3, 5, 9, 17, 33, 75。看 **DL 重建后的 PSNR/SSIM 随 K 怎么变**，以及「DL 用 1 角度能不能逼近 K=75 的质量」。

**这条曲线讲出来就是创新点**：「用 1/75 的发射数据，DL 重建逼近满配质量」——这是超声超快成像领域（减少发射次数=提高帧率）最核心的价值主张，也是 Perdios 那篇论文在解决的问题。你在自仿真上做了「1 PW vs 5 PW」，在 PICMUS 上做「1 vs 75 角度的完整曲线」，就把轴 B 从「一个点」升级成「一条可发表的规律」。

### 2.1 第 1 步：复用 11/9 的 DAS，加一个「K 角度复合」函数（自己写）

在 `stepC_picmus.py` 基础上（`rf_all`、`angles`、`das_vec`、`disp_db`、`extract_patches` 都已有了），只加：

```python
import numpy as np

def compound_das(K):
    """用均匀采样的 K 个角度做相干复合，返回 dB 图 (nz, nx)。"""
    if K == 1:
        idxs = [int(np.argmin(np.abs(angles)))]          # 1 个角度 = 0°
    else:
        idxs = np.linspace(0, len(angles)-1, K).astype(int)  # 均匀取 K 个角度
    high = np.zeros_like(low)                            # low 是 11/9 已算好的 (nz,nx)
    for k in idxs:
        high += das_vec(rf_all[k].T, angles[k])
    high /= len(idxs)
    return disp_db(high)
```
