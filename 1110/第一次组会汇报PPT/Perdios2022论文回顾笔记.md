# Perdios 2022 论文回顾笔记（组会汇报用）

> 论文：CNN-Based Image Reconstruction Method for Ultrafast Ultrasound Imaging  
> 作者：Dimitris Perdios, Manuel Vonlanthen, Florian Martinez, Marcel Arditi, Jean-Philippe Thiran（EPFL LTS5）  
> 期刊：IEEE Transactions on Ultrasonics, Ferroelectrics, and Frequency Control, vol. 69, no. 4, pp. 1154-1168, 2022

---

## 一、论文在做什么（一句话）

用 CNN 把「单平面波（单次发射）」的低质量超声图，重建到接近「合成孔径 SA（多次发射复合）」的高质量图——用约 1/100 的采集数据，达到接近金标准的图像质量。

### 背景：超声成像的根本矛盾

|      | 发射次数多  | 发射次数少          |
| ---- | ------ | -------------- |
| 图像质量 | 高（伪影少） | 低（衍射伪影严重）      |
| 帧率   | 低      | 高（能看心脏/血流等快运动） |



> 论文要解决：在「少发射」前提下，用 CNN 把图像质量补回来。

---

## 二、重点：结果图 Fig. 6 怎么讲

Fig. 6 是 2 行 × 3 列，两行是不同实验对象：

- **上排：in vitro 离体体模（78 dB）**
- **下排：in vivo 活体颈动脉（50 dB）**

每行 3 列是同一对象的三种图：

| 列       | 标注            | 含义              |
| ------- | ------------- | --------------- |
| (a)/(d) | LQ（CNN Input） | 单平面波低质量图 = 网络输入 |
| (b)/(e) | MSLAE-16      | CNN 重建图 = 网络输出  |
| (c)/(f) | HQ            | 合成孔径高质量图 = 金标准  |

### 看图三要点

1. **看 LQ → 重建 → HQ 的变化**：LQ 里点目标周围的扇形衍射条纹、栅瓣伪影，经 CNN 后大幅消失，点目标清晰锐利、背景干净，逼近 HQ。
2. **下排颈动脉证明泛化**：真实活体组织（非仿真/体模），证明网络能迁移到真实人体数据，血管壁结构保留好。
3. **动态范围不同**：上排 78 dB、下排 50 dB，说明方法在不同动态范围都有效。

---

## 三、核心结论（4 条）

1. **方法**：反投影（DAS）得低质图 → 残差 CNN 恢复高质图，专除衍射伪影（栅瓣/旁瓣/边缘波）。
2. **单平面波重建质量 ≈ SA 金标准，动态范围 > 60 dB**。
3. **采集需求降低 100 倍以上**（单次发射 vs 多次相干复合）。
4. **MSLAE 损失兼顾 HDR 与 RF 振荡，仿真训练可迁移到 in vitro / in vivo**。

---

## 四、关键差异：MSLAE 损失 vs 我的 L1

|          | 论文 MSLAE                                    | 我的复现 L1               |
| -------- | ------------------------------------------- | --------------------- |
| 全称       | 多尺度对数绝对误差                                   | 平均绝对误差                |
| 为什么要"对数" | 超声是高动态范围（HDR），强弱回波差几个数量级，取对数拉平后网络才能同时处理大小目标 | 不需要，我主要解决 speckle 过平滑 |
| 共同点      | 都避开 MSE 的过平滑问题                              | 都避开 MSE 的过平滑问题        |

> 被追问"损失函数为什么不同"时：论文用 MSLAE 处理超声 HDR 兼顾强弱回波；我用 L1 针对 speckle 过平滑，两者目标不同但都避开 MSE。

---

## 五、我的复现 vs 论文（对照表）

| 维度 | 论文 Perdios              | 我的复现                 |
| -- | ----------------------- | -------------------- |
| 输入 | 单平面波反投影/DAS 低质图         | 单角度 DAS 低质图          |
| 目标 | 多角度/SA 复合高质图            | 75 角度相干复合高质图         |
| 网络 | 残差 CNN                  | UNet（编码器-解码器+跳跃连接）   |
| 损失 | MSLAE                   | L1                   |
| 数据 | 仿真 + in vitro + in vivo | 自仿真散射体 + PICMUS 公开数据 |

**相同点**：思路一致（低质 → 高质），输入都是少角度波束形成、目标都是多角度复合。

**不同点（我的选择/创新）**：

- 网络用 UNet（跳跃连接更适合像素级映射、保空间细节）。
- 损失用 L1（更简单，同样避免过平滑）。
- 数据做到 phantom 级别，还额外验证了角度数与质量的关系（创新点）。

## 六、论文的 4 条局限 ↔ 我的对应

| 论文局限（V 节）                | 我的对应                            |
| ------------------------ | ------------------------------- |
| ① 指标依赖（PSNR/SSIM 与感知不一致） | 遇到「PSNR 升 + SSIM 降」，已用 L1 解决过平滑 |
| ② speckle 纹理重建困难（乘性噪声）   | 三分量分解定位过平滑、L1 保纹理缓解             |
| ③ 仿真训练泛化受限               | 用 PICMUS 真实 RF 数据验证，弥补短板        |
| ④ 角度数与质量关系未系统研究          | **下一步：角度稀疏采样消融（创新点）**           |

## 七、下一步：角度稀疏采样消融（创新点）

把「一个点（1→75 角度）」扩成「一条曲线（K = 1,3,5,9,17,33,75）」：

- **输入固定 = 1 角度**，只让「目标」的 K 变。
- 每个 K 训一个 DL，记录 baseline 与 DL 的 PSNR/SSIM 各一条曲线。
- **核心假设**：用很少的角度（如 3 个）+ DL，逼近 75 角度质量 → 用 1/25 发射数据换接近满配质量 → 帧率提升 25 倍。

### 临床价值

超快超声核心诉求 = 减少发射次数 = 提高帧率。若「3 角度 + DL ≈ 75 角度」成立，帧率提升 25 倍，对心脏/血流等快速运动成像有直接意义。

---

## 八、一句话总结（整篇）

> Perdios 2022 用残差 CNN 把单平面波（单次发射）低质量超声图重建到接近合成孔径质量，采集需求降低 100 倍以上；关键创新是 MSLAE 损失（取对数兼顾高动态范围与 RF 振荡），并证明仿真训练可迁移到体模和活体。Fig. 6 是核心证据：LQ 的衍射伪影被 CNN 清除，重建图逼近 HQ。我复现了同一条「低质→高质」链（UNet + L1），并据此设计了角度稀疏采样消融这一创新方向。
