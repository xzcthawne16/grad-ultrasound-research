## 1. 项目链路（PPT 的「一张图」）

```
数据 ──► 波束形成(DAS) ──► 低质/高质配对 ──► DL 重建(UNet) ──► PSNR/SSIM ──► baseline 对比
  │              │                 │                │              │

```

**一句话串讲（不看稿能说）**：先用 DAS 波束形成，把「单平面波」成像成一张低质图、把「多平面波相干复合」成像成一张高质图；再用这对低质/高质图训练一个 UNet，让它学会「低质 → 高质」的映射；最后用 PSNR/SSIM 客观验证，DL 重建要超过「直接拿低质图当结果」这个 baseline。

## 2. 三个主任务的最终结论

### 主任务 A —— SSIM 下降排查（11/9）

**问题**：DL 重建第一版出现「PSNR 升 + SSIM 降」（PSNR 24.67→29.13，SSIM 0.8584→0.4228）。

**排查方法**：把 SSIM 拆成亮度 l × 对比度 c × 结构 s 三分量，定位「哪个成分降了」。

**结论**：**过平滑（对比度 c 下降）**，不是 bug。

- 机理：MSE 的最优解是条件均值 E[高质|低质]，而超声 speckle 是随机乘性噪声，取平均会把纹理「抹平」，输出变平滑；
- 于是 PSNR（只看逐像素误差）升、SSIM（看结构纹理）降——这是「MSE 训练 + SSIM 评价」的**指标错配**典型信号。

**这一页的价值**：组会上导师一定会问「SSIM 为什么降」，能讲清楚机理 = 显得你懂指标。

---

### 主任务 B —— 调优（11/9）

三个变式，目标是在不破坏 PSNR 提升的前提下把 SSIM 拉回来：

| 方案 | 做法 | 效果 |
|------|------|------|
| 变式 A：换 L1 loss | `MSELoss → L1Loss` | **最优**，PSNR 30.25 / SSIM 0.9288，双升 |
| 变式 B：组合损失 MSE+λ(1−SSIM) | 同时优化像素误差和结构 | 可试 λ=0.05~0.2 |
| 变式 C：归一化口径 | 放宽动态范围 | 仅当 clip 比例高才做 |

**结论**：L1 损失最优，**PSNR 30.25 dB、SSIM 0.9288**，实现「PSNR + SSIM 双升」，解决了过平滑问题。

---

### 主任务 C —— PICMUS 公开数据集 DL 重建（11/9→11/10）

**数据**：PICMUS（Plane-wave Imaging Challenge in Medical UltraSound，IEEE IUS 2016）真实 RF 数据。
关键参数：**75 个平面波角度、128 阵元、采样率 20.832 MHz、声速 1540 m/s**。

**流程**：
1. 单角度（0°）DAS → 低质图；
2. 75 角度相干复合 → 高质图；
3. 同位置滑动切 patch（64×64，stride 32）→ 187 对训练样本（因 PICMUS 是静态 phantom 只有 1 帧，靠空间切块造配对）；
4. UNet 训练（L1 损失 + 减参网络 + PixelShuffle 上采样）；
5. 验证集 PSNR/SSIM + 整图重建。

**最终指标（验证集均值）**：

| 指标 | 低质 baseline | DL 重建 | 提升 |
|------|--------------|---------|------|
| PSNR | 49.85 dB | **60.15 dB** | **+10.30 dB** |
| SSIM | 0.9350 | **0.9936** | **+0.0586** |

**整图重建效果**：点目标清晰可见、背景干净、伪影大幅减少，接近 75 角度复合的高质图。

## 4. 关键调优点（体现思考深度的「讲点」）

三个调优改动，每个都能对应一个「为什么」：

| 改动 | 解决什么 |
|------|----------|
| MSE → L1 损失 | 减少过度平滑（MSE 抹平纹理，L1 保边缘） |
| 31M → 7.8M 参数（通道减半） | 抗过拟合（149 对样本 vs 3100 万参数失衡） |
| 转置卷积 → PixelShuffle | 消除棋盘伪影 |

## 5. 最重要的教训（归一化 bug，组会可主动讲）

这是一个隐蔽但极其重要的坑，主动讲出来显得你踩过坑、懂原理：

```python
# ❌ 错误：减 min 归一化
img = (img - img.min()) / (img.max() - img.min())
# 超声图 min 是极端负值(-47.58)，"背景"其实是接近0的值
# 减 min 后背景 0-(-47.58)=47.58，再除以 range 93 → 背景被抬到 0.51 中间灰度

# ✅ 正确：除以绝对最大值
img = img / np.abs(img).max()
# 背景(接近0)保持0，强散射点才是1
```

**这个 bug 的影响**：训练时高质 label 的背景变成 0.5（不合理的亮），网络学到的输出背景也是 0.5，整图显示就灰白一片。改对后 PSNR 提升从 +4.7 dB 暴涨到 **+10.3 dB**。

## 8. 创新点（轴 B：更少数据同等质量）

把「1 角度 → 75 角度」这一个点，扩成「角度数 K 从 1 到 75 的整条曲线」：

> 固定输入 = 1 角度；把高质目标换成 K 角度复合（K=1,3,5,9,17,33,75），看 DL 重建的 PSNR/SSIM 随 K 怎么变，以及「DL 用 1 角度能不能逼近 K=75 的质量」。

**讲法**：「用 1/75 的发射数据，DL 重建逼近满配质量」——这是超声超快成像领域（减少发射=提高帧率）最核心的价值主张。
