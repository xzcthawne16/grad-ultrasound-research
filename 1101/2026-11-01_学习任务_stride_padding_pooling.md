## 2. 主任务：stride/padding/池化＋小 CNN 逐层 shape（3–4 小时）

### 2.0 先定义三个词（没看懂就停，不要跳）

- **stride（步长）**：卷积窗口一次跳几格。跳 1 格输出几乎不变；跳 2 格输出大约减半。
- **padding（补边）**：在图四周垫一圈 0，让边缘像素也能被窗口「完整看到」，常用于让卷积后尺寸不变。
- **池化（pooling）**：另一种缩小尺寸的方式，把一个 2×2 小块压成 1 个数（取最大＝MaxPool，取平均＝AvgPool）。**池化没有可学习权重**，与卷积是两回事。

三者目的不同：stride/padding 是**卷积层自己的参数**；池化是**单独的一层**。今天重点是把「每层尺寸怎么变」算清楚。

### 2.1 stride：窗口一步跳几格

一维看最清楚。输入 `x = [1,2,3,4,5]`，核 `k = [1,0,-1]`（长度 3，仍是「左减右」差异核）。

- **stride=1**：起点 0、1、2，输出长度 3。
- **stride=2**：起点 0、2（起点 4 越界停止），输出长度 2。

一维公式：`输出长度 = floor((输入长度 − 核长度) / stride) + 1` → `floor((5−3)/2)+1 = 2`。

二维同样算，高和宽各算一次（padding=0 时）：

```text
out = floor((W − kernel) / stride) + 1
```

- 28×28、3×3、stride=1 → 26（昨天已见）
- 28×28、3×3、stride=2 → floor(12.5)+1 = **13**

**先自己算（发我核对）**：28×28、**5×5** 核、stride=2、padding=0，输出多大？
（答案见 2.4）

### 2.2 padding：给边缘垫一圈 0

stride=1、padding=0 时，28×28 过 3×3 变成 26×26——每过一层卷积就小 2，叠几层图就缩没了。padding 就是「补一圈 0」，让尺寸不变或缩得可控。

用昨天那张 4×4 图，padding=1 变 6×6，再过昨天的差异核：`out = 6 − 3 + 1 = 4`，**回到 4×4，和输入一样大**。

想让卷积后尺寸不变，奇数核需要的 padding 是 `(kernel−1)/2`：

- 3×3 核 → padding=1（28→28）
- 5×5 核 → padding=2（28→28）

### 2.3 池化：把一个方块压成一个数

`MaxPool2d(2)`：每个 2×2 取最大值，窗口默认 stride=2（不重叠），尺寸直接减半。`AvgPool2d(2)` 取平均。

**先自己算**：28×28 过 `MaxPool2d(2)`，输出多大？
（答案：14×14。池化不改通道数，只改空间 H、W；也没有要学习的权重。）

### 2.4 PyTorch 核对（逐段运行，先预测再核对）

**stride（一维）**：

```python
from torch import nn

x1 = torch.tensor([1., 2., 3., 4., 5.]).unsqueeze(0).unsqueeze(0)  # [1,1,5]
k1 = torch.tensor([1., 0., -1.]).unsqueeze(0).unsqueeze(0)         # [1,1,3]

```

### 2.5 拼一个小 CNN，逐层写 shape（今日核心）

关键：**想要 28→14→7，第一、二层卷积必须 padding=1**（否则 28→26→12，不是 14→7）。

```text
输入                         [1,  1, 28, 28]    1 样本，1 通道，28×28
Conv2d(1,8,3, padding=1)   → [1,  8, 28, 28]   8 通道，尺寸不变
ReLU                        → [1,  8, 28, 28]   逐元素 max(0,x)，不改 shape
MaxPool2d(2)                → [1,  8, 14, 14]   尺寸减半
Conv2d(8,16,3, padding=1)  → [1, 16, 14, 14]   16 通道，尺寸不变
ReLU                        → [1, 16, 14, 14]
MaxPool2d(2)                → [1, 16,  7,  7]   尺寸再减半
Flatten                     → [1, 784]          16×7×7 = 784
Linear(784,10)              → [1,  10]          10 个类别分数
```

三件事要看清：

1. **784 的来历**：`16 通道 × 7×7 = 784`，和原图 `28×28=784` 数值相同只是**巧合**，含义完全不同（16 张 7×7 特征图 vs 一张 28×28 原图）。
2. **只有 Conv 和 Linear 有参数**，ReLU、MaxPool、Flatten 都没有可学习权重。
3. 参数量：

```text
Conv2d(1,8,3):   8×1×3×3 + 8  = 80
Conv2d(8,16,3): 16×8×3×3 + 16 = 1168
Linear(784,10): 784×10 + 10    = 7850
合计 = 9098
```

```python
class SmallCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 8, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(8, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),

            nn.Flatten(),
            nn.Linear(16 * 7 * 7, 10),
```

### 2.8 自己写尺寸函数＋让网络自己报 shape（报告级基本功）

**（1）不看讲义，自己写一个公式函数，再和 PyTorch 核对 4 组配置：**

```python
def out_size(W, K, P=0, S=1):
    return (W + 2*P - K) // S + 1

for W, K, P, S in [(28,3,1,1), (28,3,0,2), (28,5,0,2), (7,3,1,1)]:
    c = nn.Conv2d(1, 1, kernel_size=K, padding=P, stride=S, bias=False)
    with torch.no_grad():
        y = c(torch.zeros(1, 1, W, W))
    print(f'W={W} K={K} P={P} S={S}: 公式={out_size(W,K,P,S)} 实际={y.shape[-1]}')
```

预期：每行「公式＝实际」。**这是报告里「结构尺寸可控、不是碰运气」的证据。**

**（2）不用手动数，用 forward hook 让网络自己报每层输出形状（可直接截图进报告）：**

```python
def show_shapes(model, x):
    hs, handles = [], []
    for name, m in model.named_modules():
        if isinstance(m, (nn.Conv2d, nn.MaxPool2d, nn.Flatten, nn.Linear)):
            handles.append(m.register_forward_hook(
                lambda m, i, o, name=name: hs.append((name, tuple(o.shape)))))
    with torch.no_grad():
        model(x)
    for h in handles: h.remove()
    for name, shape in hs:
        print(f'{name:40s} {shape}')

show_shapes(SmallCNN(), torch.zeros(1, 1, 28, 28))
```

预期看到 `[1,8,28,28] → [1,8,28,28] → [1,8,14,14] → ... → [1,10]`。把这张表抄进笔记，就是报告里的「模型结构表」。

## 3. 信号：FFT 概念＋rfft 入门（1–1.5 小时）

> 今天只到「概念＋rfft 入门＋单频看峰位置」，**不铺复数、窗函数、频谱泄漏全套推导**（那些留到 11/2–11/3）。一次只补一个概念。

### 3.1 概念：FFT 是干什么的

10/31 你生成了两频叠加信号 `s = sin(2π·2t) + 0.5·sin(2π·5t)`，**因为你亲手写的配方里明说了 2Hz 和 5Hz**。但现实中，如果别人只给你 `s` 一串数、不告诉你成分，你怎么知道它由哪些频率组成？

**FFT（快速傅里叶变换）就是干这件事的工具：把「时间—数值」表，变成「频率—幅值」表。** 它是 DFT（离散傅里叶变换）的高效算法，`np.fft.rfft` 一行就够。

一句话：**时域看「某个时刻信号是多少」，频域看「每个频率成分有多强」。** 横轴从「秒」换成「赫兹」。

### 3.2 先做一个「整周期单频」例子，最容易看

```python
import numpy as np
import matplotlib.pyplot as plt

fs = 100            # 采样率：每秒采 100 个点
f0 = 2              # 信号频率 2 Hz
T = 1.0             # 观察 1 秒
N = int(fs * T)     # 100 个点
t = np.arange(N) / fs              # 0, 0.01, ..., 0.99
x = np.sin(2 * np.pi * f0 * t)     # 2Hz，1 秒 = 2 个整周期

X = np.fft.rfft(x)                       # 复数结果，长度 N//2+1 = 51
freqs = np.fft.rfftfreq(N, d=1/fs)       # 频率轴：0,1,...,50 Hz
mag = np.abs(X)                          # 先看「相对大小」

plt.plot(freqs, mag)
plt.xlabel('freq (Hz)')
plt.ylabel('|X| (相对大小)')
plt.title('2Hz 信号的频谱（先看峰在哪，不纠结数值）')
plt.show()

# 峰在哪一格：
peak = int(np.argmax(mag))
print('峰所在频率：', freqs[peak], 'Hz')   # 预期 2.0
```

要点（写进笔记）：

1. `rfft` 对**实数**信号返回**非负频率**那一半，长度 `N//2+1`。
2. `rfftfreq(N, d=1/fs)` 给出对应的频率轴：从 0 到 `fs/2`（奈奎斯特频率 50 Hz），间隔 `fs/N`（这里 1 Hz）。
3. **为什么峰在 2Hz？** 因为这根轴上的「2」就是「每秒振动 2 次」的那根频率，与输入成分 `2π·2·t` 的 2 对应。

**为什么今天选「整周期」例子？** 2Hz×1s＝2 个完整周期，频率恰好落在格点上，峰又高又干净。若频率不对齐格点（如 2.3Hz），峰会「漏」到旁边——这就是「频谱泄漏」，今天先不展开，只记住「用整周期例子先看清」。

### 3.4 幅值换算（预告，今天只留个印象）

### 3.5 实际算一遍：幅值换算＋两频频谱（时间够就做，报告直接用）

你保底有 6 小时，今天把这两张图算出来，就是报告里「信号实验」的证据。

**（1）单频幅值换算**：`amp = mag * 2 / N`，2Hz 峰应从约 50 变回约 1：

```python
amp = mag * 2 / N
print('2Hz 峰幅值：', amp[np.argmax(mag)])   # 预期 ≈ 1.0
```

**（2）两频实算**（接 10/31 的预测）：`s = sin(2π·2t) + 0.5·sin(2π·5t)`，fs=100、2s、200 点：

```python
fs, T = 100, 2.0
t = np.arange(0, T, 1/fs)
s = np.sin(2*np.pi*2*t) + 0.5*np.sin(2*np.pi*5*t)

X2 = np.fft.rfft(s)
f2 = np.fft.rfftfreq(len(s), d=1/fs)
amp2 = np.abs(X2) * 2 / len(s)

for i in np.argsort(amp2)[-3:]:
    print(f'f={f2[i]:.1f} Hz  amp={amp2[i]:.2f}')

plt.plot(f2, amp2)
plt.xlabel('freq (Hz)'); plt.ylabel('amplitude')
plt.title('2Hz + 0.5*5Hz spectrum (real rfft)')
plt.show()
```

预期：**2Hz 峰≈1、5Hz 峰≈0.5**，和 10/31 的预测一致（分辨率 fs/N=0.5Hz、整周期无泄漏）。**这张图保存好，就是报告的 FFT 证据图。**
