# Grad Ultrasound Research

超声图像深度学习重建课题的日常学习沉淀仓库（一作论文冲刺）。

## 目录结构

```
2026-11/
├── 1101/ ~ 1119/   # 前期调研、选题、gap 判断
├── 1124/           # Day 1：残差修复 H2 验证 + DCL 精读
├── 1125/           # Day 2：多角度 K 曲线 + BEAM-Net 精读 + DiffPWI 前沿
└── ...
```

每个日期目录内约定三件套：

- `YYYY-MM-DD_学习任务_*.md` — 当天任务与验收标准
- `YYYY-MM-DD_实验记录_*.md` — 代码实验记录与结论
- `YYYY-MM-DD_*读书卡.md` — 论文精读/泛读读书卡（三问格式）

代码放各日期目录下的 `us_recon_*` 子目录（另有独立代码仓库 `us-recon` 管理核心训练代码）。

## 论文 PDF

论文原文 PDF 不纳入版本控制（版权与体积考虑），原文链接记录在对应读书卡的「论文信息」小节。

## 核心课题

验证深度学习超声重建是否在「去伪影」的同时「保真实组织/点散射体」——用「已知真点 + 已知消声区」的自证链，量化「去伪影 vs 保组织」的权衡。这是 DCL(2023)、Modular(2025)、BEAM-Net(2025)、DiffPWI(2026) 等正面对手均未系统覆盖的 research gap。
