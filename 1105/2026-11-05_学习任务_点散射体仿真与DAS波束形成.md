## 2. 主任务：点散射体仿真 + DAS 波束形成（4 小时，今日核心）

### 2.1 先讲清物理直觉（先定义后例子，别跳过）

**超声 B 超图是怎么来的（一句话版）：**
探头发出一个声波脉冲，声波进入人体，碰到组织里一个个「小散射体」（微小的界面/点状结构）被反射回来；探头上一排阵元各自记下回波。**同一个散射体的回波到达不同阵元的时间不同**（因为距离不同）。波束形成就是：对空间里每一个点，把各阵元「按该点的时延对齐后相加」——在真有散射体的地方，各阵元对齐了、**相干叠加变亮**；在没散射体的地方，时延对不齐、**相互抵消变暗**。把每个点算一遍，就得到一张 B 图。

**几个词先给定义：**
- **点散射体**：把组织简化成「若干发光的点」，每个点有位置 (x, z) 和反射强度 A。这是仿真里最基础的模型（真实组织是连续散射，但点模型足够让我们理解成像原理）。
- **阵元（element）**：探头上一排小换能器中的一个。仿真里用 N 个阵元沿 x 轴排开。
- **平面波发射**：所有阵元**同时**发同一个脉冲，波前是一整个平面往下传播（对应「超快超声/高帧率」，也是你导师创新轴 B 的舞台）。今天先用它。
- **DAS（Delay-And-Sum）**：先算时延（Delay）、再求和（Sum）。波束形成最基础的方法。
- **时延 τ**：声波从发射 → 到目标点 → 再反射回某个阵元，一共走的时间。

### 2.2 第 1 步：生成每个阵元的接收信号（RF）（第一项「自己写」）

**要求**：先自己写，写不出来再看下面参考。至少写出：
- 参数（声速 c、采样率 fs、阵元数 N、间距 pitch、发射脉冲）；
- 阵元位置 `elem_x`（沿 x 轴、中心在原点）；
- 散射体列表 `[[x, z, 强度], ...]`；
- 对每个阵元 i、每个散射体 k，算时延 `tau`，把发射脉冲（高斯型）按 tau 平移后叠加进 `rf[i]`。

**时延公式（平面波发射）**：
```
tau(k, i) = ( z_k + sqrt( (x_k - elem_x[i])^2 + z_k^2 ) ) / c
              └──────┘   └────────────────────────────┘
              发射路程        回波路程（散射体→阵元 i）
```

参考（写不出来再看）：

```python
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "DejaVu Sans"]
plt.rcParams["axes.unicode_minus"] = False

# ===== 1. 参数 =====
c = 1540.0          # 声速 (m/s)
fs = 40e6           # 采样率 40 MHz
N = 64              # 阵元数
pitch = 0.3e-3      # 阵元间距 0.3 mm（约一个波长）
sigma = 0.05e-6     # 发射脉冲的高斯宽度 50 ns

# ===== 2. 阵元位置（沿 x 轴，中心在原点）=====
elem_x = (np.arange(N) - (N - 1) / 2) * pitch          # shape (N,)

# ===== 3. 散射体 [x(m), z(m), 强度] =====
scatterers = np.array([
    [ 0.0e-3, 15e-3, 1.0],
    [ 3.0e-3, 20e-3, 0.7],
    [-3.0e-3, 25e-3, 0.5],
])

# ===== 4. 接收时间轴（覆盖最远散射体往返）=====
z_max = 40e-3
t_axis = np.arange(0, 2 * z_max / c, 1 / fs)          # shape (T,)

# ===== 5. 生成每个阵元的接收信号 =====
rf = np.zeros((N, len(t_axis)))
for xk, zk, amp in scatterers:
    for i in range(N):
        tau = (zk + np.sqrt((xk - elem_x[i]) ** 2 + zk ** 2)) / c
        rf[i] += amp * np.exp(-((t_axis - tau) ** 2) / (2 * sigma ** 2))

# 看一眼两个阵元的信号：不同阵元，回波到达时间不一样
plt.figure()
plt.plot(t_axis * 1e6, rf[0], label="阵元 0（左端）")
plt.plot(t_axis * 1e6, rf[N // 2], label=f"阵元 {N // 2}（中间）")
plt.xlabel("时间 (μs)"); plt.ylabel("幅度"); plt.legend()
plt.title("两个阵元的接收信号（同一个散射体，时延不同）")
plt.show()
```

### 2.3 第 2 步：DAS 波束形成（第二项「自己写」，今日核心）

**要求**：对成像网格每个像素 (x, z)，算它对每个阵元的时延，把各阵元在该时延处的值加起来，得到该像素强度。

**先手推（写在注释里）**：像素 (x, z) 对阵元 i 的时延
```
tau_i(x, z) = ( z + sqrt( (x - elem_x[i])^2 + z^2 ) ) / c
```
为什么是 `z`（发射）＋ `sqrt(...)`（接收）？发射是平面波，波前从探头平面走到深度 z，路程就是 z；接收是从 (x,z) 回到阵元 i 的直线距离。

参考（朴素版慢但直观，跑一次即可；慢就用 2.4 的向量化版）：

```python
# ===== 6. DAS 波束形成（朴素三重循环，理解用）=====
nx, nz = 256, 512
x_grid = np.linspace(-10e-3, 10e-3, nx)
z_grid = np.linspace(2e-3, 40e-3, nz)

image = np.zeros((nz, nx))
for j, z in enumerate(z_grid):
    for i_idx, x in enumerate(x_grid):
        s = 0.0
        for i in range(N):
            tau = (z + np.sqrt((x - elem_x[i]) ** 2 + z ** 2)) / c
            k = int(round(tau * fs))
            if 0 <= k < len(t_axis):
                s += rf[i, k]
        image[j, i_idx] = s
```

### 2.4 向量化 DAS（快，实际跑用这个）

```python
# 向量化：只循环 N 次，每次向量化处理整张图
X, Z = np.meshgrid(x_grid, z_grid)                  # 各 (nz, nx)
image = np.zeros((nz, nx))
for i in range(N):
    tau = (Z + np.sqrt((X - elem_x[i]) ** 2 + Z ** 2)) / c   # (nz, nx)
    idx = np.round(tau * fs).astype(int)
    idx = np.clip(idx, 0, len(t_axis) - 1)
    image += rf[i, idx]                             # 高级索引，形状 (nz, nx)

# ===== 7. 显示（对数压缩，超声常用）=====
disp = np.abs(image)
disp_db = 20 * np.log10(disp / disp.max() + 1e-6)

plt.imshow(disp_db,
           extent=[x_grid[0]*1e3, x_grid[-1]*1e3, z_grid[-1]*1e3, z_grid[0]*1e3],
           cmap="gray", aspect="auto", vmin=-60, vmax=0)
plt.colorbar(label="dB")
plt.xlabel("x (mm)"); plt.ylabel("z (mm)")
```

## 3. 信号：波束形成的几何时延手算（1 小时，与主任务联动）

不写代码，纯手算一个例子，把「时延」吃透：

**题**：声速 c=1540 m/s，阵元间距 0.3mm，阵元 0 在 x=0。有一个散射体在 (x=0, z=15mm)。问：
1. 发射是平面波，波前从探头（z=0）到散射体（z=15mm）走多久？
2. 散射体回波回到**阵元 0**（正好在正上方）走多久？总时延 τ = ？
3. 如果散射体在 (x=4.8mm, z=15mm)（偏移 4.8mm），回波回到**阵元 0** 的直线距离是多少？（用勾股定理），总时延比上一问大了多少？

**参考思路**：
1. 发射路程 = 15mm → t_发射 = 15e-3 / 1540 ≈ 9.74 μs。
2. 回波路程 = 15mm（正上方）→ t_回波 = 9.74 μs → τ = 19.48 μs。
3. 回波路程 = sqrt(4.8² + 15²) = sqrt(23.04 + 225) = sqrt(248.04) ≈ 15.75mm → t_回波 ≈ 10.23 μs → τ ≈ 9.74 + 10.23 = 19.97 μs，比正上方大了约 0.49 μs。

**结论写进笔记**：同一深度、偏离阵元越远的散射体，回波到该阵元**越晚**；DAS 就是按每个点各自的这个时延去「对齐」再求和，把不同阵元的回波在正确的点「凑」到一起。
